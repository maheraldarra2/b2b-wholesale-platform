# B2B Wholesale Platform (PHP)

A PHP-based web platform connecting factories, wholesalers, and retailers.  
Factories add products, wholesalers buy in bulk, and retailers order smaller quantities with online payment.

## Features
- Role-based login (Factory / Wholesaler / Retailer)
- Product catalog with filters
- Cart + Orders system
- Online payment integration
- Dashboards for each user type
- Stock management
- Image upload for products

## Tech Stack
- PHP Native
- MySQL
- HTML / CSS / JS
- PayPal / Paymob API

## Installation
1. Import the SQL file
2. Configure `/includes/db.php`
3. Run the project on localhost or hosting
